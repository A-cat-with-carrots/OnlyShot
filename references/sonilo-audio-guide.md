# Sonilo AI 配乐 / 音效指南（阶段 4.D 可选自动化）

对接剪辑步骤：初剪在剪映拼好后，把成片交给 Sonilo API，自动生成跟着剪辑点和剧情情绪走的 BGM，时长自动对齐；也能按画面生成同步音效。原有的手动搜曲库流程不受影响，想用哪条路都行。

> **先看这里（第三方服务）**：Sonilo 是第三方付费服务，这份指南和脚本由 Sonilo 团队贡献（#5）。
> - 视频会上传到 Sonilo 的服务器处理，保存和使用按它的[隐私政策](https://sonilo.com/privacy-policy)。
> - 计费：配乐、音效都是每输出 1 秒 18 积分，每次至少 15 秒、200 积分；免费档每两周 2,000 积分（约 110 秒），一集 180 秒的配乐约 3,240 积分。
> - 授权：免费档仅限个人、非商用；发到平台变现属于商用，要 Pro 及以上（或符合条件的 API 用户），以 [Sonilo 条款](https://sonilo.com/pricing)为准。生成的音频带不可听的来源水印。
> - 以上按 2026-11-10 的官网和 API 文档整理，以官网为准。

脚本：`scripts/生成配乐.py`（纯标准库，无第三方依赖）。配乐见示例 1-3，音效见示例 4。

## 准备（一次性）

1. https://sonilo.com 注册拿 API Key（免费档每两周 2,000 积分，约够 110 秒，仅限个人非商用）
2. 设环境变量（Windows 在 Git Bash 里跑，和 dreamina 一样）：

```bash
export SONILO_API_KEY=sk-xxx
```

Key 只走环境变量，不要写进代码、配置文件或仓库。

**计费**：按视频秒数计费，生成失败自动退款；自己主动重跑是新的一次扣费，所以先想清楚 prompt 再跑，别靠反复抽卡。

**时长上限**（先看这个再跑）：

| 接口 | 视频上限 | OnlyShot 场景 |
|------|---------|--------------|
| 配乐 | **6 分钟** | 整集初剪（180-195s）直接跑，富余很大 |
| 音效 | **8 分钟** | 整集（180-195s）可以直接跑；只跑关键段更省（按秒计费） |

超上限接口直接拒绝（422），不创建任务、不扣费。本地装了 ffprobe 的话，脚本会在上传前先拦一道。

## 示例 1：整集初剪配乐（最常用）

剪映流程小调整：段落拼好、配音上完，**BGM 先不加**，导出一版初剪 MP4，然后：

```bash
python scripts/生成配乐.py 分集/第01集_胡同重生/初剪.mp4
```

不写 prompt 也能跑，模型自己读剪辑点和情绪节奏。产出落在视频旁边：

```
分集/第01集_胡同重生/
├── 初剪.mp4
├── 初剪_配乐.m4a          ← 导回剪映当 BGM 轨
└── 初剪_配乐_授权.json    ← license_id 留档（商用凭据，别删）
```

有配音的成片，人声处音乐会自动压低（尽力而为，最终以试听为准）。若结果目录多出带 `_ducked` / `_mux` 后缀的附加音轨，优先试听那版。

## 示例 2：带风格提示的配乐

prompt 是可选的风格提示。写之前先记住一条实测结论：**和画面一致比写得漂亮更重要**。prompt 和成片讲同一个故事（同样的题材、节奏、爆点），效果稳过凭空写一段华丽的音乐描述。

```bash
python scripts/生成配乐.py 分集/第01集_胡同重生/初剪.mp4 \
  --prompt "国风悬疑短剧配乐，古筝和低音鼓，开场克制压抑，30 秒左右主角踢开木门时来一个爆点，之后转紧张追逐，结尾停在悬念上不收尾。不要人声，不要电子舞曲鼓点"
```

写法要点：

| 要点 | 写 | 别写 |
|------|-----|------|
| 曲风 + 配器 | "古筝和低音鼓" | "好听的音乐" |
| 能量走向 | "开场克制，30 秒左右跟着踢门动作起爆点" | "在 28.5 秒准时爆" |
| 相对结构 | "结尾停在悬念上" | 精确时间戳（对齐是尽力而为，不是帧级保证） |
| 排除项 | "不要人声，不要电子舞曲鼓点" | ——排除项同样是尽力而为，生成后要试听验证 |

`04_节奏地图.json` 里的 7 招节点（30s 爆破 / 60s 爽点 / 90s 反转……）就是现成的锚点素材，直接翻译成"XX 秒左右 + 画面上发生什么"写进 prompt。

## 示例 3：反转集的两段式结构

短剧最常见的音乐需求：**反转前后要判若两曲**。分段式的写法直接描述结构，后端能解析就按结构规划生成，解析不了就退回整曲风格提示——两种结果都能用，以试听为准。

```bash
python scripts/生成配乐.py 分集/第08集_身份揭晓/初剪.mp4 \
  --prompt "两段式结构：反转前压着走，弱奏钢琴加低音持续音，克制铺垫不出头；主角亮出真实身份的反转点起全面打开，弦乐和鼓组进场，一路强推到结尾收在大和弦上。不要人声"
```

锚点写"画面上发生什么"（"主角亮出真实身份时"），别写精确秒数。`04_节奏地图.json` 的 90s 反转节点就是这类 prompt 的现成素材。

## 题材 prompt 模板速查表

复制进 `--prompt`，改两个词就能用。每条都是同一个配方：**曲风 + 配器 / 能量走向（跟画面动作）/ 排除项**。

| 题材 | 模板 |
|------|------|
| 国风悬疑 | 国风悬疑配乐，古筝、箫和低音鼓，开场克制压抑，跟着爆点动作起势，结尾停在悬念上不收尾。不要人声，不要电子舞曲鼓点 |
| 都市逆袭打脸 | 现代都市爽剧配乐，钢琴铺底加电子鼓点，前段隐忍低走，打脸时刻鼓点全开，一路推到结尾。不要人声 |
| 情感虐恋 | 情感虐恋配乐，弦乐和钢琴，慢起，情绪层层往上压，泪点处只留钢琴独奏，结尾弦乐收拢。不要打击乐，不要人声 |
| 甜宠日常 | 甜宠轻喜配乐，木吉他和铃铛质感的轻打击，轻快不抢戏，甜点时刻旋律亮一下。不要电子音色，不要人声 |
| 悬疑惊悚 | 悬疑惊悚配乐，低音弦乐持续音加心跳式鼓点，全程低压推进，惊吓点一记重击后突然静默。不要旋律钩子，不要人声 |
| 高燃战斗 | 高燃战斗配乐，交响鼓组和铜管，跟打斗节奏走，招式命中处落重音，结尾大和弦收。不要人声 |

## 示例 4：关键段音效（segments 把声音钉到动作上）

音效按输出秒数计费，对**关键段**单跑最划算：从 `视频段/` 里挑爆点 / 卡点段（每段 4-10s，远低于上限）。比如 grid13 是"主角踢开木门"：

`音效分段.json`：

```json
[
  {"start": 0,   "end": 1.5, "prompt": "皮鞋踩过散落玻璃碴，碎裂声由远及近"},
  {"start": 1.5, "end": 3,   "prompt": "木门被一脚踹开，门框断裂，铰链崩飞"},
  {"start": 3,   "end": 5,   "prompt": "门板砸在地面弹了一下，室内回声，灰尘簌簌往下落"}
]
```

```bash
python scripts/生成配乐.py 分集/第01集_胡同重生/视频段/段13.mp4 --sfx --segments 音效分段.json
```

产出 `段13_音效.m4a` + `段13_音效_授权.json`，导回剪映音效轨、对齐该段起点。

segments 怎么写：

1. **写物理，不写概念**。"轮胎咬碎石"能出声，"刺激的声音"出不了。名词写材质，动词用碰撞类（踩、砸、崩、擦、碎）。
2. **一段一个声音事件**。每段只放一个主导事件和它的伴生声（踹门 = 撞击 + 门框断裂 + 铰链崩飞，算一个事件）。"刹车……然后一声鸟叫"是两个事件，拆两段。
3. **音量不要写进 prompt**。"响一点""有冲击力"没用，混音电平不受 prompt 控制，回剪映调。

segments 规则（后端强校验，验不过整单拒绝、不扣费，脚本也会提前拦）：

- 最多 30 段；首段 `start` 必须是 0；段与段首尾相接（上段 `end` = 下段 `start`）
- 每段 `end` > `start`；每段 `prompt` 非空、≤200 字符
- 末段 `end` 不必到视频结尾，没盖到的尾巴就是没音效
- 不写 `--segments` 也行：模型通读画面自己决定，适合先跑一版听听

不确定某个动作发生在第几秒？抽帧看：`ffmpeg -i 段13.mp4 -vf fps=10 帧_%03d.png`。

## 常见问题

| 现象 | 处理 |
|------|------|
| 等待超时 | 任务还在后台跑（已计费不浪费），`python scripts/生成配乐.py --resume <task_id>` 找回 |
| 401 | SONILO_API_KEY 没设对 |
| 402 | 余额不足，sonilo.com 查用量 |
| 413 | 文件过大，剪映导出用 1080p / 中码率 |
| 422 | 视频超时长上限，或 segments 不满足规则（看报错明细） |
| 429 | 触发频率限制，稍等再跑 |
| "不要人声"结果还是有人声 | 排除项是尽力而为，没有后端强制。把想要的写得更具体（比如点名配器），比堆更多"不要"管用 |
| 爆点没踩上 | 配乐：把"XX 秒左右 + 画面动作"的锚点写进 prompt 再跑一版；音效：给爆点单独一段，材质词写得更具体（都是新扣费，先诊断再重跑） |
